### How a case is run and matched

1. The single input `.ts` `@Component` is read and its SOURCE passed to
   `compile_component_source`. If the front-end returns an error (providers,
   queries, host bindings, `templateUrl`, multi-class, `@Directive`-only, etc.)
   the case is **SKIPPED** and counted by reason.
2. The expected golden is the per-case `.js` that contains `ɵɵdefineComponent`
   (NOT `GOLDEN_PARTIAL.js` / `ngDeclareComponent` goldens — those are skipped as
   partial-only).
3. We extract the balanced `ɵɵdefineComponent({...})` block from BOTH the golden
   and our emit, canonicalise (strip imports/comments, unify the `i0.`/`$r3$.`
   Ivy ref prefix, collapse `$name$`/`_rN` placeholders + `__AttributeMarker__`
   tokens, drop `type:`, collapse whitespace), then require every `…`/`// ...`
   ellipsis-delimited golden fragment to appear, IN ORDER, in our output.
   Instruction names, argument order and slot indices are preserved.
