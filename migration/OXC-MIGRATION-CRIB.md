# OXC 0.29 → 0.133 Migration Crib Sheet

Generated by the `api-breakage-scout` workflow (5 agents reading installed crate sources).
Authoritative for migrating `apps/rust/authoring/src/angular/`.

## Crate / import changes
- **Add dep `oxc_str = "0.133.0"`** — `Ident`, `Str`, `CompactStr` live here now.
- `VisitMut` moved: `use oxc_ast::VisitMut` → **`use oxc_ast_visit::VisitMut`** (add `oxc_ast_visit` dep). `AstKind`/`AstType` stay in `oxc_ast`.
- `oxc_span::Atom` is **GONE** → AST `.name` fields are now `oxc_str::Ident<'a>`. `use oxc_str::Ident;`
- `oxc_span::CompactString` no longer re-exported → `use oxc_str::CompactStr;`
- `LogicalOperator` path unchanged (`oxc::syntax::operator` / `oxc_syntax::operator`).
- `SourceType`, `SPAN`, `Span` unchanged in `oxc_span`.

## Strings (the dominant change)
- `Atom<'a>` → `Ident<'a>`. Comparisons (`name == "foo"`), `.as_str()`, `.into_string()`, `String::from`, `Display` all still work — read paths just need the type name updated.
- `builder.atom(s)` / `new_atom` **REMOVED**. Use `builder.ident(&str) -> Ident<'a>` (names) or `builder.str(&str) -> Str<'a>` (string values). Both allocate into arena.
- AstBuilder name params now take `A1: Into<Ident<'a>>`. A `&'static str` literal works directly. **Runtime `String`/transient `&str` must be arena-allocated**: `self.ast.ident(&s)` then pass it (or `Ident::from_in(s, alloc)`).
- `.to_compact_string()` → `ident.to_compact_str() -> oxc_str::CompactStr` (or `CompactStr::new(s)`).

## Removed `::new` constructors → AstBuilder
- `IdentifierReference::new(span,name)` → `ast.identifier_reference(span, name)`
- `IdentifierName::new(span,name)` → `ast.identifier_name(span, name)`
- `BindingIdentifier::new(span,name)` → `ast.binding_identifier(span, name)`
- `StringLiteral::new(span,v)` → `ast.string_literal(span, v, None)`
- `BindingPattern::new_with_kind(kind)` → **BindingPattern is now an ENUM**; use `ast.binding_pattern_binding_identifier(span, name)` etc.

## Enum / field changes
- `Argument::Expression(Expression::X(..))` → **flattened**: `Argument::X(..)` directly (e.g. `Argument::ObjectExpression(o)`, `Argument::Identifier(i)`). Build from expr: `Argument::from(expr)` / `expr.into()`.
- `PropertyKey::Identifier(..)` → **`PropertyKey::StaticIdentifier(Box<IdentifierName>)`**.
- `BindingPattern` struct→enum: `param.pattern.type_annotation` → **`param.type_annotation`** (moved onto `FormalParameter`); match `param.pattern` directly (variants = old `BindingPatternKind`).
- `Modifiers` / `Modifiers::empty()` — **does not exist**; drop entirely (declare-ness via `declare: bool`).
- Every node gained internal `node_id` (defaulted by builder) — **no struct literals**; build via AstBuilder.

## oxc_semantic Scoping merge
- `ScopeTree` & `SymbolTable` → unified **`oxc_semantic::Scoping`**.
- `semantic.symbols()` / `semantic.scopes()` → **`semantic.scoping()`**; `semantic.scopes_mut()` → **`semantic.scoping_mut()`**. `source_type()` unchanged.
- `add_binding(ScopeId::new(0), name: CompactStr, SymbolId::new(0))` → `scoping_mut().add_binding(scope_id, name: Ident<'_>, symbol_id)` (name is now `Ident`, arena-backed).
- **`generate_uid` is GONE** from semantic (moved to `oxc_traverse::TraverseCtx::generate_uid_name(name, &allocator)`). With only a `Scoping`, mint names manually. → *We add a simple `AngularCtx::generate_uid(&str) -> CompactStr` shim (no uniquification; documented simplification).*
- `ScopeId::new`/`SymbolId::new` still work (now NonMaxU32 — `new(u32::MAX)` panics).

## Parser / Semantic entry points
- `Parser::new(&alloc, src, source_type).parse()` → `ParserReturn { program, errors, panicked, .. }` — unchanged.
- `SemanticBuilder::new(src)` → **`SemanticBuilder::new()`** (no source arg); `.build(&program)` → `{ semantic, errors }`; borrows `&'a Program<'a>`.

## Project-specific decisions
- DI code was orphaned/untested → no behavior to preserve byte-for-byte; we wire it into `lib.rs` and add a fresh snapshot test as the new baseline.
- `generate_uid` shim returns `CompactStr::new(name)` (no uniquification) — acceptable until the proper `render3` factory port (Phase 4) replaces this hand-rolled DI codegen.
