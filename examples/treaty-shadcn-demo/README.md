# treaty-shadcn-demo

A minimal standalone Angular **gallery** app that consumes the built
[`treaty-shadcn`](../treaty-shadcn) showcase library and renders all six
components across their full variant/size surface.

It is the consumer-side counterpart to the packagr proof: `treaty-shadcn`
packages six components — authored across `.treaty`, Treaty JSX, and plain React
— to a publishable Angular `dist/`; this app imports that **built** library and
lays the components out in a gallery, the way a real downstream app would.

## What it shows

| Component | Surface authored in | Gallery coverage |
| --------- | ------------------- | ---------------- |
| **Button** | Treaty JSX (`.tsx`) | every variant (`default`/`outline`/`ghost`/`destructive`) × every size (`sm`/`md`/`lg`) + disabled |
| **Badge**  | `.treaty` SFC | every variant (`default`/`secondary`/`destructive`/`outline`) |
| **Card**   | plain **React** (`.tsx`) | title + description + expand/collapse toggle |
| **Alert**  | plain **React** (`.tsx`) | info / success / warning / error, dismissible (`×`) and not |
| **Input**  | Treaty JSX (`.tsx`) | text / email / password / disabled, each with a bound value |
| **Switch** | `.treaty` SFC | on / off / disabled, each labelled |

## How it's wired

Standard standalone Angular — Treaty is a compiler, not a host:

- `index.html` hosts `<app-root>` and loads `src/main.ts`.
- `src/main.ts` is the plain bootstrap (`bootstrapApplication`, zoneless).
- `src/app/app-root.component.ts` is a plain `@Component` `.ts` (the third Treaty
  authoring surface, lowered to Ivy by `@treaty/vite`). It imports the six
  components **by value** from the built library and references them
  **selectorlessly** in the template (`<Button>`, `<Badge>`, …) — each lowered
  component registers `selectors: [["button"], ["Button"]]`, so the PascalCase
  tag matches the library def at runtime, exactly like the everything-app's
  greeter-page hosts `<Greeter />`.
- `vite.config.ts` contributes the `treaty()` plugin and resolves the
  `treaty-shadcn` package + per-component subpath exports to their compiled
  `dist/<name>/index.mjs` (the bundler equivalent of the package `exports` map),
  plus a tiny `enforce: 'pre'` plugin that type-strips the library's published
  `.mjs` (some authored TS — `input<T>()` generics, a `type` alias — survives the
  packagr lowering, and Vite treats a `.mjs` as plain JS).

## Build + verify

```bash
# Real production build through the treaty() plugin chain.
vite build                     # or: npm run build:vite

# Full end-to-end harness: real `vite build` + headless jsdom boot, asserting
# every component instantiates and renders content. Exit 0 on green.
node full-build.e2e.mjs        # or: npm run e2e:full-build
```

The harness proves:

- the app **builds**: app-root lowered + all six library components present as
  AOT Ivy (`ɵɵdefineComponent`), **zero** residual `ɵɵngDeclare*`, **no**
  `@angular/compiler` (no JIT), no `@angular/compiler-cli`, no `@babel/core`;
- the app **boots** headlessly with no JIT error and **no** bare `<ng-component>`
  host (every selectorless component renders under its filename-derived selector);
- **Button**, **Badge**, **Card**, **Input**, and **Switch** render non-empty
  content (labels / variant classes / titles / bound values / knob + disabled).

### Recorded upstream gap

`Alert` title/message/× and the `Switch` **label text** are recorded (not failed)
as blocked by a documented **upstream Rust-compiler** bug: the signals-auto-call
pass invokes a bare signal read in a plain `{{ x() }}` interpolation but **misses
it** in an `@if`/`&&` guard (`{!dismissed && …}` lowers to `!ctx.dismissed`,
should be `!ctx.dismissed()`) and in a nested-template interpolation
(`{{ label }}` lowers to `ctx.label`, should be `ctx.label()`). The Alert host
tags still instantiate and link AOT — only the guarded/nested signal text is
missing. The same gap reproduces when the library sources are compiled fresh
(not only from the packaged dist), proving it is a compiler defect, not a demo or
consumption defect. The harness's `UPSTREAM_SIGNAL_AUTOCALL_BUG` switch records
it precisely and asserts it stays exactly the known gap; flip it to `false` once
the auto-call pass covers guard + nested-interpolation positions.

> The consumed library `dist/` is regenerated by
> `cargo test -p treaty-packagr package_treaty_shadcn_showcase_to_dist`.
